Monitoramento de Servidores

Descrição
Algoritmo desenvolvido em Portugol, utilizando o VisuAlg, para automatizar o monitoramento de servidores de uma empresa de hospedagem.
O programa recebe os tempos de resposta de diferentes servidores, calcula a média das amostras coletadas e identifica aquele que apresenta o pior desempenho.

Conceitos aplicados
Variáveis e tipos de dados;
Estruturas de repetição;
Estruturas condicionais;
Contadores e acumuladores;
Operações aritméticas;
Cálculo de média.

Objetivo
Praticar conceitos fundamentais de lógica de programação por meio da resolução de um problema prático.

Linguagem e ferramenta
Linguagem: Portugol
Ferramenta: VisuAlg
